# 禁用語規則（banwords.rules.json）

曝光資源的禁用語只讀 `shopee2/banwords.rules.json`，**要新增或修改禁用語就直接改這個檔**。
（2026-11-23 起不再使用 banwords.xlsx：TP 不收 xlsx，原本的轉檔工具也已移除。）

## 每一條規則的格式

```json
{
  "row": 69,
  "scope": "出現",
  "keyword": "撒",
  "rule": "自動改成\"灑\"",
  "message": "",
  "exclude": ""
}
```

| 欄位 | 意思 | 怎麼填 |
|---|---|---|
| `row` | 編號 | 只是方便對照，接著最後一號往下編即可 |
| `scope` | 範圍 | 固定填 `"出現"` |
| `keyword` | 要抓的字詞 | 例：`"購物金"` |
| `rule` | 抓到後怎麼處理 | 二選一：`"自動改成\"新字詞\""`（自動替換），或 `"直接無法輸入"`（直接刪掉，打不進去） |
| `message` | 提示文字 | 選填，抓到時顯示給使用者；不需要就填 `""` |
| `exclude` | 例外詞 | 選填，這些詞裡的 keyword 不處理；多個用 `、` `，` `,` `/` 或換行隔開，例：`"萬元、百元、千元"` |

## 注意

- 每條規則之間要有逗號，最後一條後面**不能**有逗號；字串裡的雙引號要寫成 `\"`。
- 單一中文數字（一、二…十、兩…）且「自動改成」純數字的規則，會自動支援右鍵「豁免」，不用另外設定。
- 改完可以先檢查格式是否正確（在 MS 資料夾執行）：

  ```
  node -e "const r=JSON.parse(require('fs').readFileSync('shopee2/banwords.rules.json','utf8'));console.log('OK',r.length,'條')"
  ```

  格式錯誤時，曝光資源開啟時也會跳出「讀取 banwords.rules.json 失敗」的提示。
